These are common command of Linux

| Command     | Full Name                                                          | 功能說明            |
| ----------- | ------------------------------------------------------------------ | --------------- |
| **`ls`**    | **l**i**s**t                                                       | 列出目錄內容          |
| **`cd`**    | **c**hange **d**irectory                                           | 切換目錄            |
| **`pwd`**   | **p**rint **w**orking **d**irectory                                | 顯示目前所在的路徑       |
| **`mkdir`** | **m**a**k**e **d**irectory                                         | 建立新目錄           |
| **`cp`**    | **c**o**p**y                                                       | 複製檔案或目錄         |
| **`mv`**    | **m**o**v**e                                                       | 移動檔案、目錄或將其改名    |
| **`rm`**    | **r**e**m**ove                                                     | 刪除檔案或目錄         |
| **`cat`**   | **cat**enate                                                       | 查看檔案內容（原意為連接檔案） |
| **`grep`**  | **g**lobally search for a **r**egular **e**xpression and **p**rint | 篩選 / 過濾文字內容     |
