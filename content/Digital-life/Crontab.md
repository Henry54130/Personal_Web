`crontab` 是 Linux / Unix 系統中用來設定**定時自動執行任務**（Cron Job）的工具

---

## 一、常用指令

在終端機（Terminal）中輸入以下指令：

| 指令           | 說明                                                 |
| ------------ | -------------------------------------------------- |
| `crontab -e` | **編輯**目前使用者的排程任務（第一次使用會讓你選擇文字編輯器，如 `nano` 或 `vim`） |
| `crontab -l` | **查看**目前所有的排程任務列表                                  |
| `crontab -r` | **刪除**目前所有的排程任務                                    |

---

## 二、 語法

`crontab` 中的每一列都代表一個任務，格式由 **5 個時間欄位** + **要執行的指令** 組成：

```text
*   *   *   *   *   要執行的指令
│   │   │   │   │
│   │   │   │   └── 星期幾 (0 - 6) (0 或 7 代表星期日)
│   │   │   └────── 月份 (1 - 12)
│   │   └────────── 日期 (1 - 31)
│   └────────────── 小時 (0 - 23)
└────────────────── 分鐘 (0 - 59)

```

### 特殊符號說明

* `*`：代表**每一個**單位（例如在「分鐘」位置放 `*` 代表每分鐘）。
* `,`：用來分隔多個時間點（例如 `10,30` 代表第 10 及第 30 分鐘）。
* `-`：代表時間區間（例如 `1-5` 在星期欄位代表週一至週五）。
* `/*/n`：代表**每隔 $n$ 個單位**執行一次（例如 `*/15` 在分鐘欄位代表每 15 分鐘）。

---

## 三、 常見範例參考

```bash
# 1. 每分鐘執行一次腳本
* * 
* * * /bin/bash /home/user/script.sh

# 2. 每天凌晨 02:30 執行備份
30 2 * * * /home/user/backup.sh

# 3. 每每週一至週五的早上 8:00 執行
0 8 * * 1-5 /home/user/morning_report.sh

# 4. 每 15 分鐘執行一次
*/15 * * * * /usr/bin/python3 /home/user/check_status.py

# 5. 每月 1 號與 15 號的夜間 23:00 執行
0 23 1,15 * * /home/user/biweekly_task.sh

```
