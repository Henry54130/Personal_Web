假如你已經安裝termux
### 操作步驟

#### 步驟 1：環境安裝與初始化
在 Termux 執行以完成套件安裝、Termux-X11 App 下載、Ubuntu 容器部署與 XFCE 桌面安裝：

```bash
# 1. 更新系統並安裝 X11 Repo
pkg update && pkg upgrade -y && pkg install x11-repo -y && pkg update

# 2. 安裝核心工具、PRoot 與 VirGL GPU 加速器
(pkg install termux-x11-nightly -y || pkg install termux-x11 -y)
pkg install proot-distro virglrenderer-android dbus wget android-tools -y

# 3. 下載並安裝 Termux-X11 APK（彈出安裝視窗時點擊安裝）
wget [https://github.com/termux/termux-x11/releases/download/nightly/termux-x11-universal-debug.apk](https://github.com/termux/termux-x11/releases/download/nightly/termux-x11-universal-debug.apk) -O termux-x11.apk
termux-open termux-x11.apk

# 4. 安裝 Ubuntu 容器
proot-distro install ubuntu

# 5. 進入 Ubuntu 安裝 XFCE4、Mesa 驅動與基礎套件
proot-distro login ubuntu --shared-tmp -- bash -c "
apt update && apt upgrade -y && \
apt install xfce4 xfce4-goodies dbus-x11 \
xubuntu-wallpapers gnome-backgrounds gnome-icon-theme \
libgl1-mesa-dri mesa-utils software-properties-gtk synaptic \
fonts-wqy-zenhei curl -y
"
```

#### 步驟 2：建立一鍵啟動腳本 (`start_linux.sh`)
```bash
cat << 'EOF' > start_linux.sh
#!/bin/bash
# 1. 清理舊 Session 與鎖定檔
killall -9 termux-x11 Xwayland virgl_test_server_android dbus-daemon 2>/dev/null
pkill -f termux-x11 2>/dev/null
rm -rf $TMPDIR/.X11-unix/X1 $TMPDIR/X1-lock /tmp/.X11-unix/X1 /tmp/X1-lock

# 2. 啟動 X11 與 VirGL 服務
termux-x11 :1 &
sleep 1
virgl_test_server_android --angle-gl &
sleep 1

# 3. 啟動 Termux-X11 App
am start --user 0 -n com.termux.x11/com.termux.x11.MainActivity

# 4. 載入硬體加速環境變數並啟動 XFCE
proot-distro login ubuntu --shared-tmp -- bash -c "
export DISPLAY=:1
export XDG_RUNTIME_DIR=/tmp/runtime-root
mkdir -p \$XDG_RUNTIME_DIR
chmod 700 \$XDG_RUNTIME_DIR

# VirGL 硬體加速設定
export GALLIUM_DRIVER=virpipe
export MESA_GL_VERSION_OVERRIDE=4.0
export MESA_GLES_VERSION_OVERRIDE=3.0
export LIBGL_ALWAYS_SOFTWARE=0

# DPI 與桌面設定
mkdir -p ~/Desktop
chmod +x /usr/share/applications/*.desktop ~/Desktop/*.desktop 2>/dev/null
echo 'Xft.dpi: 144' > ~/.Xresources
xrdb -merge ~/.Xresources 2>/dev/null

# 啟動桌面
dbus-launch --exit-with-session startxfce4
"
EOF

chmod +x start_linux.sh
```

#### 步驟 3：日常啟動
日後於 Termux 執行即可進入桌面：
```bash
./start_linux.sh
```

### 建議修改與除錯設定

#### 1. 驗證 GPU 硬體加速狀態
進入桌面後於終端機執行：
```bash
glxinfo | grep "OpenGL renderer"
glxgears
```
* **加速成功：** Renderer 顯示為 `virgl`，`glxgears` 幀率穩定。

#### 2. DPI / 字體縮放調整
* 預設 DPI 設為 `144`。如需變更，進入系統選單 ➔ **Settings** ➔ **Appearance** ➔ **Fonts** ➔ **DPI** 進行微調。

#### 3. 停用 Android Phantom Process Killer
透過 ADB（或 Termux 配對 Wireless Debugging）執行以解除背景程序限制：
```bash
adb shell device_config put activity_manager max_phantom_processes 2147483647
```
